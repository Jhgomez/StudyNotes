# APIs

* **Android Developer Preview 3**: The Android XR SDK Developer Preview 3 is a significant update for Android developers, offering tools and APIs to create XR experiences
  for glasses and headsets. This preview version includes new libraries and tools to simplify the development of XR applications, making it easier for developers to
  leverage the capabilities of the Android XR platform. The SDK also includes updates for the Galaxy XR headset and other devices, enhancing the immersive experiences
  developers can create.

* **ARCore** for Jetpack XR contains a geospatial API called **Visual Positioning Service** which provides directions based on orientation. The **Geoaspatial API** helps
  us build content triggers and location-specific actions. ARCore has motion tracking which allows to build dynamic experiences that respond intuitively to user movement
  like a head tilt

* Two new APIs designed for AI glasses are:
      * **Jetpack Glimmer**: Compose UI toolkit for AI glasses, contains components like Cards, Lists, Stacks, etc
      * **Jetpack Projected library**: Is a foundational API that lets you bring existing Android mobile apps directly to AI Glasses, it helps set audio configurations and access
        the glasses camera from a mobile app

* Gemini Live API: This AI API now works with AI glasses, it was developed in conjuction with the Firebase Logic team
